# Промпт для анализа проекта: chatradar

Ты работаешь с экспортом проекта. Сначала изучи структуру, manifest, профиль проекта, план экспорта и отчёты безопасности. Затем выполни задачи ниже.

## Цели

- Оценить архитектуру, слои, модульность и связность.
- Найти вероятные ошибки, сломанные крайние случаи и логические несоответствия.
- Выявить недостающие тесты и предложить практичный тест-план.

## Формат ответа

- Сначала перечисли критичные проблемы с файлами и причинами.
- Затем предложи небольшие улучшения с низким риском внедрения.
- Отдельно отметь тесты, которые нужно добавить или обновить.
- Не переписывай проект целиком без необходимости.
