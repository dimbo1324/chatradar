# AI Assistant Rule Modules

Single source of truth for the rules that govern every AI assistant (Claude Code first,
Codex, Gemini CLI and any future agent) working in this repository.

## How it works

```text
.ai/universal/*.md   Portable rules, valid for ANY project. No project names, paths or
                     stack specifics.
.ai/project/*.md     Rules for THIS project: map, commands, domain rules, progress
                     tracking, command reference.
CLAUDE.md            Claude Code entry point; imports every module with native @path syntax.
AGENTS.md            Codex (and any AGENTS.md reader) entry point. GENERATED by
                     concatenating the same modules. Never edit by hand.
GEMINI.md            Gemini CLI entry point; imports AGENTS.md.
.claude/agents|skills  Project subagents and skills — the source.
.codex/agents|skills   GENERATED mirror of .claude/agents|skills.
.ai/CHANGELOG.md     History of rule changes: what, why, when, who decided.
```

Modules load in filename order: `universal/01..NN` first, then `project/10..NN`. Project
rules win over universal rules when they conflict.

## Editing rules

1. Edit or add a module under `.ai/universal/` or `.ai/project/` (or an agent or skill
   under `.claude/`).
2. Record the change in `.ai/CHANGELOG.md`.
3. Regenerate: `just agents` (`uv run python scripts/sync_agents.py`) — writes `AGENTS.md`
   and `.codex/agents|skills`.
4. Commit the source, the changelog entry and the regenerated files together.

`just check`, the pre-commit hook and CI fail while anything generated is out of date.
`CLAUDE.md` needs no regeneration: Claude Code resolves `@` imports at session start.

The protocol for changing rules — when it is allowed, who decides — is
`universal/08-rules-evolution.md`. Read it before touching a module.

## Size budget and module tiers

Codex reads at most 32 KiB of project instructions; `sync_agents.py` fails above 30 KiB.

- **inline** (default) — embedded in `AGENTS.md` in full.
- **extended** — only the title, path and essence are embedded. Opt in with
  `<!-- tier: extended -->` in the first five lines, and put
  `> **Essence.** One sentence covering the module's core rules.` right after the title.

Extended modules bind exactly like inline ones. `CLAUDE.md` imports every module
regardless of tier.
